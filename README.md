# OIFF Planner

Personal schedule planner for the **Orcas Island Film Festival 2026**. The app will help browse films, rank favorites, and build a conflict-aware festival schedule. This repository currently contains only the project foundation and deployment setup.

## Production

Pushes to `main` deploy automatically to GitHub Pages:

**https://mattheuscolyn.github.io/oiff-planner/**

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

## Lint

```bash
npm run lint
```
